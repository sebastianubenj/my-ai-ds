# Description

Supporting line under a page Title. Body-lg, subtle foreground. Same type on every breakpoint.

## Basic

<Canvas of={DescriptionStories.Basic} />

## Usage

Prefer `PageHeader` when Title and Description appear together. Use Description on its own only when the title is already rendered.

Do not use it for field helper or error copy; that is `FieldDescriptionOrRequirement`. Form-level errors are `FormAlert`.

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | — | The supporting text. |
| `className` | `string` | — | Adds custom CSS classes to the paragraph. |

Also accepts native `<p>` attributes via `React.ComponentProps<"p">`.
