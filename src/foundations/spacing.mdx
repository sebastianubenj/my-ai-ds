# Spacing

The design system's spacing scale. Specimens consume the existing `primitives.spacing.*` CSS variables. This page is documentation, not a public Spacing component.

Spacing is a **primitive-only** foundation. There is no semantic spacing layer. Components consume these tokens directly for gap, padding, and control dimensions.

The scale uses a 4px base relationship: Figma name × 4 = px. Names resemble a Tailwind-style scale, but the steps are project-specific. Do not treat this as a standard Tailwind scale or an 8px grid.

Fractional-looking names use Figma's comma notation. For example, `spacing/2,25` is 9px (`--primitives-spacing-2-25`).

This page documents the token scale, not component-specific spacing decisions.
