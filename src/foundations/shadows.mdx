# Shadows

The design system's shadow architecture. Specimens consume the existing CSS variables. This page is documentation, not a public Shadow component.

Shadows are composed as **Semantics → Effect Style**. The semantic `shadow/popover` tokens hold the y, blur, spread, and color of each layer as raw values. The Effect Style `shadows/popover` is the canonical complete recipe. There are no primitive shadow tokens.

Figma currently binds this shadow only on **Select** (`SelectContent`). Component demonstrations belong on the Select docs, not this Foundation.

Shadow colors contain their own alpha. They stay in this Foundation; they are not Colors tokens and are not Opacity tokens.
