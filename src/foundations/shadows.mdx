# Shadows

The design system's shadow architecture. Specimens consume the existing CSS variables. This page is documentation, not a public Shadow component.

Shadows are composed as **Primitives → Semantics → Effect Style**. Primitive geometry and colors are the parts. Semantic `shadow/popover` maps the md geometry into a role. The Effect Style `shadows/popover` is the canonical complete recipe.

Figma currently binds this shadow only on **Select** (`SelectContent`). Component demonstrations belong on the Select docs, not this Foundation.

Unused primitive scale steps remain valid published tokens. Unused means no Figma binding and not an alias target of a bound semantic token. `shadows/scale/md/*` is **Used** because semantic popover aliases those primitives, even though the md tokens have no direct node bindings.

Shadow colors contain their own alpha. They stay in this Foundation; they are not Colors tokens and are not Opacity tokens.

## Popover Recipe

The only complete Figma Effect Style. Consume the generated `--effect-shadows-popover-*` variables as a stacked `box-shadow`. There is no semantic x token; offset X comes from primitive `shadows/scale/x` (0).

## Primitive Scale

Decomposed y, blur, and spread parts, plus shared x. Specimens compose `box-shadow` from those CSS variables and `primitives.shadows.color.black-10` so the geometry is visible. That color choice is a scale demonstration. It is **not** an official Effect Style. Do not treat sm, lg, xl, or 2xl as published recipes.

## Primitive Colors

Effect colors with baked-in alpha. All four are currently unused as Figma variable bindings. Semantic popover color is the same hex as `black-10` (`#0000001a`) but is a raw value, not an alias.
