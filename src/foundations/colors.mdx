# Colors

Primitive palette → semantic roles → components. Specimens consume the existing CSS variables. This page is documentation, not a public Color component.

Components consume **semantic** colors. Primitive colors are the palette those roles alias.

Semantic colors have Light and Dark modes from the Figma **Semantic Colors** collection. Use the Theme toolbar. Swatches read the CSS variables, so they flip with the theme. Primitive colors do not change: they are the palette both modes alias.
