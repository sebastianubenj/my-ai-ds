# Colors

Primitive palette → semantic roles → components. Specimens consume the existing CSS variables. This page is documentation, not a public Color component.

Components consume **semantic** colors. Primitive colors are the palette those roles alias.

The design system currently documents a **single light theme**. Figma collections have one mode, and semantic color tokens have no dark variants.
