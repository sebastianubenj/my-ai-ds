# Navigation

One bar. Desktop shows the mark, primary links, and search. Below the `md` breakpoint it shows the mark, search, and menu.

The menu is one shared panel, passed as `menu`. It is not a submenu of each primary link, and the open bar does not mark a current link. `open` is controlled. On mobile the menu button opens it and the header becomes the close control (`x` on the right). Pass `onBack` to add the back control on the left. Desktop has no extra trigger; set `open` to show the panel under the same bar.

Do not use `Link` for these items. `Link` is underlined text. `NavigationLink` is the bar label. `NavigationMenuLink` is the large panel link.

The closed bar fill is `colors/background/primary-blur`. Its blur is `glass/navigation/frost`. The open panel is solid `colors/background/primary`. The desktop area under the panel uses `colors/background/primary-blur` and `background-blur/navigation`.
