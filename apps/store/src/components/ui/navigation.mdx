# Navigation

One bar. Desktop shows the mark, primary links, and the icon buttons passed as `children`. Below `md` (768px) it shows the mark, those icon buttons, and the menu; links move into the mobile `menu` panel.

`appearance="empty"` is the same bar with only the mark (`logoHref`, `logoLabel`). There is no menu, search, or bag.

`children` is one slot: `NavigationLink`, `NavigationSearchTrigger`, `NavigationBagTrigger`, and `NavigationIconButton` in bar order. Links hide below `md`. Icon buttons stay on the bar.

Do not use `Link` for these items. `Link` is underlined text. `NavigationLink` is the bar label. `NavigationMenuLink` is the large panel link.

## Behavior

- **Desktop panel** — `NavigationLink` with `menu` (usually `NavigationSection`) opens a panel under the bar on hover, like the Apple global nav. The panel is one surface over the page with a scrim; it does not push content. Hovering another link swaps content. `Escape`, a press outside, or leaving the bar and panel closes it. A link without `menu` only navigates. On touch, the first tap on a link with `menu` opens the panel; the second follows `href`.
- **Search** — `NavigationSearchTrigger` opens search on click or `Enter`, never on hover. The field takes focus. Same close rules as the panel. Drive text with `searchValue`, `onSearchValueChange`, and `onSearchSubmit` on `Navigation`. Open from outside with `value="search"`.
- **Bag** — `NavigationBagTrigger` opens like search (click / `Enter`, not hover). Empty: “Your bag is empty”, Log in hint, My profile. `loggedIn` swaps hint and Log out. With `items`: “Bag”, Review bag, up to five rows, overflow copy, My profile. A count badge overlays the bag icon (1–99, then `99+`) and is part of the button name. Open from outside with `value="bag"`.
- **Keyboard** — Focusing a link with `menu` shows a chevron named by `menuLabel`. `Enter` on the link follows `href`; `Enter` on the chevron opens the panel.
- **Fixed bar** — The bar is `fixed`. An in-flow spacer keeps page content below it. Panels open under the bar.
- **Controlled value** — Give each link a `value`. `value` / `defaultValue` / `onValueChange` on `Navigation` set the open desktop panel (`null` closes it).
- **Mobile menu** — `menu` on `Navigation` is the shared panel. Per-link `menu` is unused below `md`. `open` is controlled when set. The header is close (`closeLabel`); with a submenu, back (`backLabel`) appears. Two levels: a `NavigationMenuLink` with `submenu` pushes the second level instead of navigating. `onBack` runs on back.
- **Mobile search and bag** — Full-screen views with the same field or bag body. Closing returns focus to the trigger.

Motion uses `semantics.motion` (durations, stagger, delay-reveal, standard easing). Reduced motion turns transitions off.

## API

The TypeScript props are the contract. These tables explain usage.

### Navigation

Required chrome: `logoHref`, `logoLabel`. Product appearance also requires `searchLabel`, `clearSearchLabel`, `menuLabel`, `closeLabel`, and `backLabel`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `appearance` | `"product"` &#124; `"empty"` | `"product"` | `empty` is mark-only. Omit or `product` for the full bar. |
| `logoHref` | `string` | — | Destination of the mark. The mark is decorative; this link is the name. |
| `logoLabel` | `string` | — | Accessible name of the mark link. |
| `children` | `React.ReactNode` | — | Bar items. Product only. |
| `menu` | `React.ReactNode` | — | Mobile panel. Desktop uses each `NavigationLink` `menu`. Product only. |
| `open` | `boolean` | — | Controlled mobile panel. Uncontrolled when omitted. |
| `defaultOpen` | `boolean` | — | Initially open mobile panel when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | — | Mobile panel open changes. |
| `value` | `string` &#124; `null` | — | Open desktop panel: a link `value`, `"search"`, `"bag"`, or `null`. |
| `defaultValue` | `string` &#124; `null` | — | Initially open desktop panel when uncontrolled. |
| `onValueChange` | `(value: string &#124; null) => void` | — | Desktop panel value changes. |
| `searchLabel` | `string` | — | Search button name, and the field name and placeholder. |
| `clearSearchLabel` | `string` | — | Name of the clear button in the search field. |
| `searchValue` | `string` | — | Search text. Controlled when set. |
| `onSearchValueChange` | `(value: string) => void` | — | Search text changes. |
| `onSearchSubmit` | `(value: string) => void` | — | Search form submit. |
| `onSearch` | `() => void` | — | Runs when the search button is pressed, before the panel opens. |
| `menuLabel` | `string` | — | Name of the mobile menu button. |
| `closeLabel` | `string` | — | Name of the mobile close control. |
| `backLabel` | `string` | — | Name of the mobile back control on the second level. |
| `onBack` | `() => void` | — | Runs when back is pressed. |
| `onMenu` | `() => void` | — | Runs when the menu button is pressed. |
| `className` | `string` | — | Classes on the public chrome wrapper. |

Also supports native `<header>` attributes except `children` and `defaultValue`. `ref` is the `header`. Product-only props are invalid when `appearance="empty"`.

`NavigationSearchTrigger` must be a child of `Navigation`. It has no labels of its own; it uses `searchLabel` from the root. Optional `className`.

`NavigationSearch` is the field used in both search panels. Apps usually drive it through the root search props rather than mounting it.

### NavigationLink

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | — | Destination. Click and Enter on the link follow it. |
| `children` | `React.ReactNode` | — | Bar label. |
| `value` | `string` | generated | Id for `Navigation` `value` / `defaultValue`. |
| `menu` | `React.ReactNode` | — | Desktop panel, usually `NavigationSection`. Required together with `menuLabel`. |
| `menuLabel` | `string` | — | Name of the focus chevron that opens the panel. Required when `menu` is set. |
| `className` | `string` | — | Classes on the link. |

Also supports native `<a>` attributes. `ref` is the anchor. Hidden below `md`.

### NavigationSection

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `heading` | `string` | — | Section label. Omit on the first mobile section when it has no heading. |
| `children` | `React.ReactNode` | — | Usually `NavigationMenuLink` items. |
| `className` | `string` | — | Classes on the section. |

### NavigationMenuLink

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | — | Destination. Always followed in the desktop panel. |
| `submenu` | `React.ReactNode` | — | Below `md`, opens this content as the second mobile level instead of navigating. |
| `className` | `string` | — | Classes on the link. |

Also supports native `<a>` attributes. `ref` is the anchor.

### NavigationBagTrigger

Must be a child of `Navigation`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | — | Name of the bag button when the count is 0. Count is appended when there are units. |
| `signInHref` | `string` | — | `href` of Log in on the empty hint and on My profile. |
| `signInLabel` | `string` | `"Log in"` | Label of those Log in links. |
| `emptyTitle` | `string` | `"Your bag is empty"` | Empty-state heading. |
| `emptyHint` | `string` | copy by `loggedIn` | Hint under the heading. Defaults: saved-items copy, or “Start adding items” when `loggedIn`. |
| `loggedIn` | `boolean` | `false` | Hides the empty-state Log in link; My profile shows Log out. |
| `onLogOut` | `() => void` | — | Log out under My profile when `loggedIn`. |
| `profileTitle` | `string` | `"My profile"` | Heading above the session control. |
| `logOutLabel` | `string` | `"Log out"` | Log out button label. |
| `items` | `NavigationBagItem[]` | — | Loaded bag. Omit for empty. Count is the sum of item quantities (default 1 each). |
| `title` | `string` | `"Bag"` | Loaded-state heading. |
| `reviewLabel` | `string` | `"Review bag"` | Review bag control. |
| `onReview` | `() => void` | — | Review bag action. |
| `onSignInClick` | mouse handler | — | Extra handler on Log in anchors. |
| `className` | `string` | — | Classes on the trigger. |

`NavigationBagItem`: `name`, `src`, `alt`, optional `quantity` (for example `"x2"`).

### NavigationIconButton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `IconName` | — | Icon from the registry. |
| `className` | `string` | — | Classes on the button. |

Also supports native `<button>` attributes. Give an accessible name (`aria-label`). Hidden on mobile while the menu, search, or bag view is open.
